# booking-rental-kendaraan

Program sederhana untuk melakukan booking kendaraan menggunakan C++.

## Menjalankan

Clone repository:

```bash
git clone https://github.com/annsrlhh771/booking-rental-kendaraan.git
cd booking-rental-kendaraan
```

Compile:

```bash
g++ src/main.cpp -o booking
```

Jalankan:

```bash
./booking
```

Untuk Windows:

```bash
booking.exe
```
